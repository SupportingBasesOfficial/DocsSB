# MAIN_PATH_RITUAL

## Purpose

This file defines the official human operating ritual for using the workspace through the main Codex path.

---

## Official Ritual

### Step 1
Open the workspace root (wherever the ecosystem is placed).

### Step 2
Confirm the workspace is trusted.

### Step 3
Use Codex in Chat mode first.

### Step 4
For a new serious project:
- ask Codex to read AGENTS.md
- ask Codex to read the doctrine core
- provide the project impulse
- begin with discovery only

### Step 5
Do not allow file creation before discovery unless session scaffolding is explicitly intended.

### Step 6
Only move to Agent mode when actual workspace execution is desired.

### Step 7
Only after discovery is answered may the project move toward consolidation.

### Step 8
For Stable state work, ensure the AI activates the 12 mega-tech protocols (files 23-34) during delivery and verification. The Consolidation Moment ritual (see `ENGINEERING_WORK_DOCTRINE/21_OPERATIONAL_STATES.md`) must be completed before work enters Stable state.

---

## Main Rule

Chat mode = think, discover, consolidate, review  
Agent mode = execute

## Protection Rule

No real project instance should be manually created outside doctrine-driven action.
