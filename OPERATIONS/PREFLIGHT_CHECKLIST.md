# PREFLIGHT_CHECKLIST

> **Doctrine version:** 0.8.1

## Before starting a real project session

Confirm the following:

1. Workspace root is open
2. `AGENTS.md` is present at workspace root (sole AI activation)
3. doctrine folder is present (35 files, 00-34)
4. Projects folder is present
5. active AI path is clear
6. `README.md` is present (workspace documentation for humans)
7. preferred AI tool is ready or fallback path is intentionally being used
8. no project is being created manually outside doctrine action
9. operational state is known (Exploratory / Formative / Stable) before work begins

## Rule

No real project instance should be manually created outside doctrine-driven execution.

## Tool Note

Any AI tool with access to `AGENTS.md` satisfies the activation requirement. Codex is the current preferred path. See `TOOL_AGNOSTIC_PATH.md` for full compatibility details.

## State Note

Before any work, classify the operational state. Exploratory = throwaway, no payload. Formative = shaping, lighter standards. Stable = production-grade, full mega-tech protocols. See `ENGINEERING_WORK_DOCTRINE/21_OPERATIONAL_STATES.md`.
